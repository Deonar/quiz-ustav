# Тест зі статутів ЗСУ

Веб-тест для перевірки знань військовослужбовців:

- **Дисциплінарний статут ЗСУ** — ст. 1–6
- **Статут внутрішньої служби ЗСУ** — ст. 28–32, 35–38, 49–57, 119–120
- **БСА ч. 2** — обов'язки командира взводу

## Можливості
- вибір розділів і кількості питань (10 / 20 / 30 / усі);
- режим «Навчання» (правильна відповідь і пояснення одразу) та «Іспит» (результат у кінці);
- перемішування питань і варіантів відповідей;
- таймер (1 хв на питання), оцінка за 5-бальною шкалою, статистика по розділах;
- розбір помилок, «Повторити помилки», друк результату.

## Запуск
Відкрити `index.html` у браузері (працює офлайн) або увімкнути GitHub Pages для гілки.

## Редагування питань
Усі питання — у `questions.js`:

```js
{ s: "ds", q: "Текст питання", a: ["правильна", "хибна", "хибна"], c: 0, e: "Пояснення" }
```
`s` — id розділу з `SECTIONS`, `c` — індекс правильної відповіді (варіанти перемішуються автоматично).

> ⚠️ Питання складено за текстами статутів без доступу до офіційного сайту zakon.rada.gov.ua.
> Перед використанням звірте формулювання з чинною редакцією (особливо номери статей СВС і БСА ч. 2).
